Project Picker by sisimomo, vendored unchanged from:
https://github.com/sisimomo/herdr-sisimomo-mods/tree/88d126d37d6500d3c5e828a7aef14adab4808e6c/project-picker

Cmd-N opens the picker. Type a repository name and press Enter to focus its
existing space or create one. Settings in the picker control the scan root,
depth and ignored folders per machine. Defaults scan the home folder to depth
4. Git worktrees and submodules (which use .git files) are not listed.
